# Design System Creation
Entry conditions: Approved direction and screen inventory.
Inspection: Find existing repeated colors, type and layout patterns.
Implementation: Implement semantic light/dark tokens and reusable components before consumer migration.
Quality checks: Contrast, semantic roles, 48px targets and scaled text.
Failure handling: keep diagnostics free of private content; fix the concrete failure, rerun its relevant
check, and mark device/provider absence explicitly. Do not fabricate screenshots or test passes.
Completion: Catalog matches actual component constructors and token source.
