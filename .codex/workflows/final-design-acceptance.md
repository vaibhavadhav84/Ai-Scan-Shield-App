# Final Design Acceptance
Entry conditions: Integrated redesign.
Inspection: Review design acceptance criteria, feature matrix and current diffs.
Implementation: Format, analyze, run widget/integration/backend regression checks and build Android.
Quality checks: Screenshots inspected; security meaning preserved; no introduced failing checks.
Failure handling: keep diagnostics free of private content; fix the concrete failure, rerun its relevant
check, and mark device/provider absence explicitly. Do not fabricate screenshots or test passes.
Completion: Report changed files, actual checks, inspected screens and remaining dependencies.
